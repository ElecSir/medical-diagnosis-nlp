# Medical Diagnosis NLP

Учебный проект по обработке медицинских текстов и классификации диагнозов по МКБ-10.

## Цель

Разработать прототип, который анализирует текст медицинского эпикриза и предлагает соответствующий код МКБ-10.

## Планируемые технологии

- Python
- pandas, NumPy
- scikit-learn
- PyTorch
- Streamlit
- lxml

## Структура проекта

- `data/` — исходные и обработанные данные
- `notebooks/` — анализ данных и эксперименты
- `src/` — основной программный код
- `app/` — веб-интерфейс
- `models/` — артефакты обученных моделей
- `reports/` — результаты экспериментов
- `tests/` — автоматические тесты

## Этапы разработки

1. Аудит и анализ XML-данных.
2. Извлечение диагнозов и подготовка датасета.
3. Очистка и предобработка текстов.
4. Обучение baseline-модели.
5. Обучение нейронной сети на PyTorch.
6. Оценка качества моделей.
7. Создание интерфейса на Streamlit.

## Важное ограничение

Проект является учебным исследовательским прототипом. Он не предназначен для постановки реальных медицинских диагнозов или замены заключения врача.

Медицинские документы и персональные данные не должны публиковаться в репозитории.
